# 评分反馈与提示的完整纠正

日期：2026-09-06。执行者：Codex。数据库与浏览器使用合成输入，未写入真实学习记录。

## 问题与改动

此前只能纠正逐项分数、理由、作答引文及引用；模型的遗漏、误解、提示和补救材料不能
纠正。这使真实评分中“要求补充题目未要求的内容”只能留在原反馈里。

纠正合同增加可选 findings，携带答对、遗漏、误解、下一步提示、补救材料五部分完整
快照。可以移除不成立的条目，或修改文字和冻结来源。changes 可为空以保持全部分数。
服务端深拷贝后重放并验证：空列表与缺失字段不同；提示必填，补救材料至少一条；
未知/重复引用、不完整数据、过期 hash 或重用请求 ID 改内容均拒绝。

前端新增“纠正反馈与提示”，支持逐条添加、移除、编辑及引用选择。保存失败保留草稿、
原请求 ID 和原版本；不会用刷新后的 hash 强行覆盖。当前反馈、原始模型反馈及历次
修改分别可见。分数编辑与反馈编辑互斥，切换评分任务时重建编辑器，避免混用草稿。

改动复用原 correction_json，没有新增数据库表、索引、依赖或模型调用。原模型输入、
输出和用量不被改写，原评分合同与 hash 算法不变；旧纠正省略 findings 后序列化保持。
保存纠正不会应用评分或更新复习安排。接口、部署顺序及保留兼容重放的回滚要求已写入
`docs/decisions/fsrs-mastery-mapping.md`。
