## 问题与改动

PR-13 / PR-16 截图验收入口 `VisualAssetUploadPanel` 原先独立选择第一份
`created_by=generation` 修订和 `evidence[0]`。历史运行重验后，两者可能来自不同修订，
服务端按 `evidence.id + revision_id` 检查会拒绝登记。

现在必须明确选择运行记录，修订 ID 从该记录的 `revision_id` 解析；记录列表显示修订号、
工具、时间与记录 ID，选中后显示工件 ID、代码指纹及历史归档边界。没有对应修订的证据
不提供选择，刷新移除原记录时不能提交，不会自动改选另一记录。上传期间禁用重复提交，
失败保留错误反馈。登记仍为人工采集、权利 pending，不提升运行验证状态。

沿用 core-api 已有修订/章节/工作区和证据匹配检查，没有修改后端合同、母稿或数据库结构。
