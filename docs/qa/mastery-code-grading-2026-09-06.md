## 发现与修复

`Generator.Assess` 原先只检查外层任务 context；当适配器较短的 deadline 到期时，
其错误被转换为普通 `ErrProviderFailed`。现仅提取标准 DeadlineExceeded/Canceled
分类并返回安全常量，让现有任务服务记录 timeout/cancelled；不回传带来源正文的
错误链，不更改时限，不重试 Provider，不改写历史失败收据。

`TestAdapterCancellationKeepsSafeClassification` 在旧代码对超时和取消两例均失败，
修复后通过，并检查无正文泄漏、保留已知用量、单次调用及无有效反馈。
相关应用、领域、HTTP 测试与全量 `go test ./...`（含架构）均实际通过，构建使用
backend 的 Go 1.26.0。无新迁移、依赖、前端产品代码或生产部署。

源码核对显示 `assessment-learner-code` 含完整源文件，提示已有实际 path、原始 content
及禁止引用 JSON 转义文本的规则。第二批收据没有被拒绝的模型正文，因此尚不能确定
引文不匹配的具体字符或路径；不能推断为评分算法错误或直接放宽逐字门禁。
后续应先让固定 QA 样本的诊断能定位拒绝引文，再补正确/错误及匹配运行报告的代表性
验收，随后验证生产纠正与应用链路。PR-14、PR-16 和总开发目标仍未完成。
