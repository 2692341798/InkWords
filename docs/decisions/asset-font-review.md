# 冻结图片内部字体补证

日期：2026-09-13。范围：本地教材出版审校，不代表授予许可或自动识别字体。

带截图的 PDF 同时包含渲染器排版的文字和图片内已经绘制的字形。现有受限 Fontconfig
来源集合只证明前者；PNG/JPEG 不含可执行字体不等于画面没有需要核对的字体来源。
过去带图构建始终被字体门禁拒绝，需要独立证据路径而非删除检查。

复用 `inkwords.rights-amendment.v1` 的追加记录、前序 CAS、授权、证据引用和完成时间，
新增可选 `asset_font_review`，其自身版本为 `inkwords.asset-font-review.v1`。嵌套记录包含
冻结 asset ID、内容 SHA-256、`raster` 载体、整图核对范围，以及以下互斥判断：

- `no_text`：审阅者已检查整张图没有文字/字形，字体数组必须为空。
- `identified_fonts`：有文字且字体来源全部识别，1–64 个唯一字体文件引用。每项绑定
  `font-file:sha256:…` 的独立权利项 ID 和确切补证 ID；空补证 ID 明确引用原件。

审阅者及授权、事实证据使用父补证字段，不另造自动/真人来源。未知格式、SVG/录屏等
载体不接受；图中字形仍未识别时省略此记录，不能猜测 `no_text`。普通权利 ready 不自动
变成字体 ready。用户需以完整图片区域核对为依据；此合同不执行 OCR 或声称软件能证明
审阅者没有漏字。

core-api 只接受与该构建冻结 assets 匹配的 ID/hash/图片类型。记录存入现有 JSONB，
没有新表、迁移、索引、依赖或跨服务调用。原权利项与母稿均不变。同请求 ID 的精确重试
读回原件，改动字体记录也会改变 input hash。普通原件不能直接附带此核对，必须追加有
审阅来源的补证。证据引用可以尚待补齐，但未满足下述条件时不会放行。

export-service 重新解析完整权利前序链；只读取素材最新补证中的字体记录，不沿用更早
版本。素材权利必须 ready；引用字体必须属于同一项目/构建、类型为 font、对应文件哈希、
状态 ready，当前补证 ID 必须等于记录所引用的版本。字体权利改版即使仍 ready，也会使
图片字体声明过期。下一次素材补证未附字体记录即撤下有效声明，历史仍可审计。

正常 HTML 渲染路径先核对图片字节哈希、PNG/JPEG 解码和大小预算，再接受其 data URI。
SVG/object/embed/iframe/canvas/video 和外部图像仍拒绝；原 PDF/AST/HTML 绑定校验继续
执行。只有已核对的图片和当前受限渲染字体权利都齐备，才移除 PDF 字体这一个阻断。
其它权利、运行、发展性、真人/AI来源、试学和 publication_candidate 状态均保持独立。
ZIP 的 `rights-ledger.json` 原样保留嵌套证据；`rights.json` 保留有效作品权利快照。

前端在打开补证时捕获冻结图片和当前字体版本，默认尚未核对；不因后台刷新偷偷替换
用户勾选的版本。字体来源未齐时不给可勾选的字体项；有文字但未选择字体不能提交。
失败保留请求 ID、图片和字体版本，表单保存期间禁用编辑。历史显示范围、图片哈希及
字体版本，明确省略新声明会撤下旧结论。

回退：无需回滚数据库。旧程序会忽略可选字段，但旧出口仍拒绝所有图片字体载体，
因此不会因不理解新字段而错误通过。应保留 JSONB 历史；旧程序再追加普通补证会按
上述规则撤下字体声明，升级后需显式重新核对。当前 r17 真实五项权利仍 pending，
这项实现不直接使其出版就绪。
