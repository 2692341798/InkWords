# 离线 Go 依赖供给

日期：2026-09-13。状态：依赖包、组合链路及本地工具的项目显式选择已实现；页面自动流程与真实运行尚未启用。

真实 Gin 动手章需要固定依赖。当前沙箱保持空模块缓存、GOPROXY=off、GOTOOLCHAIN=local、
只读工件及禁网隔离。采用由操作者核对并按清单哈希选择的 vendor 包，将依赖字节纳入
教学工件，而不是挂载宿主缓存、接收正文中的依赖下载命令或运行导入目标仓库。

[Go 官方模块文档](https://go.dev/ref/mod#vendoring)说明，vendor 模式的构建和测试从
vendor 目录加载包，版本表与 go.mod 必须一致；Go 本身不保证 vendor 内容未被修改。
因此本项目额外固定每个文件的路径、大小、SHA-256，以及模块版本、go.sum 的两类 h1。

## 已实现边界

- `GoDependencyManifest` 格式 `inkwords.go-offline-dependencies.v1`；来源模块、版本、
  提交、精确工具链及完整文件表由操作者提供。清单本身的预期 SHA-256 必须来自已核对
  的配置，不能信任文件里的自我声明或从母稿导入路径自动推断授权。
- `LoadOfflineGoBundle` 只读取规则文件，最多 4,096 文件、64 MiB 依赖数据、2 MiB
  清单。拒绝额外/缺失文件、链接、路径逃逸、哈希/大小错误、重复记录与未知清单字段。
  只接收 go.mod、go.sum、vendor/；构建元数据不得含 replace、exclude、tool 等指令。
  主模块、精确工具链、require、模块 checksum、vendor 版本和文件归属互相核对。
- 模块语法与版本使用已有 `golang.org/x/mod v0.38.0`；仅把它从 indirect 标记改为
  直接依赖，没有添加版本或安装依赖。加载器不联网、不调用 Go、不编译/运行内容。
- `ManuscriptGoInputForOfflineBundle` 必须收到与已核对来源完全一致的模块/版本/提交
  和工具链。保留候选的 main.go/main_test.go 原字节，只替换操作者的构建元数据并附加
  依赖/清单；v3 工件 ID 同时绑定候选、正文哈希、工具链和依赖清单哈希。
  依赖字节变化也会改变内容树哈希，从而让原运行证据失效。
- 只读命令 `textbook-dependency-inspect` 检查指定目录与清单，输出结构化结果，明确
  `activated=false`、`executed=false`。来源真实性及出版许可不能由哈希检查替代。

普通教学工件仍限制 8 MiB。显式携带已核对清单哈希的组合入口分别限制正文 8 MiB、
依赖 64 MiB、清单 2 MiB，总计最多 74 MiB、4,099 文件。普通入口拒绝 vendor 与
依赖清单命名空间，不能借依赖预算扩大正文。写入、解析、私有快照及沙箱复制采用同一
校验；依赖文件必须完全符合清单，正文仅允许 main.go/main_test.go。

执行清单新增可选 dependency_manifest_hash，空值省略，旧 v1 清单序列化哈希不变。
新字段参与清单及验证输入哈希；runner 核对依赖清单、执行清单与实际工具链一致后，
仅把校验过的私有快照交给执行器，完成后清理。沙箱复制再次核对内容树哈希，保留原
禁网、只读和资源限制。导出从对应章节或冻结构建的执行清单取得依赖哈希并携带锁文件。

真实依赖树的存储/复制/冻结导出文件解析夹具已通过，共 2,198 文件、35,853,261 字节。
该夹具仅加入操作者的占位正文，未登记为教材、未执行代码；不能表述为 Gin 样章验收。
代码尚未部署。见 `docs/qa/go-dependency-artifacts-2026-09-13.md`。

证据包，拒绝来源变化和错误归属，不回退到无依赖工件。选择保存为执行清单的可选

预检、独立 PostgreSQL 登记边界及后端全量通过；未登记、执行或部署。
